# あいろ（Art Insight Log）

> **体験し、残った芯をことばに。そして制作へ。**

鑑賞ログと制作をつなぐアプリ。

映画、展覧会、舞台——鑑賞のあと、何かが残る。
でもそれは、ただ書き留めるだけでは自分の中に根づかない。

「あいろ」は、感じたことと、その理由をたどりながら、
まだ形になっていない言葉を、少しずつすくい上げる。

記録ではなく、言葉が生まれていく洞。

公開URL：[https://oga-lab.github.io/airo/](https://oga-lab.github.io/airo/)

---

## 5つの場所

| 場所 | 役割 |
|---|---|
| **あいろ** | 鑑賞体験を記入する場所（空気→印象→分析→とりね） |
| **ログ一覧** | 過去のあいろをふりかえる場所 |
| **いんさいと** | 蓄積されたあいろの傾向が見える場所 |
| **とりね洞** | とりね（一言に凝縮された芯）が漂い、残り香として立ち上がる空間 |
| **制作** | 芯から制作へ。そのログ |

体験を入れて、芯を取り出し、蓄積し、制作へつなぐ。

---

## とりねについて

**とりね**は、体験を凝縮した一言。

分析や要約ではなく、体験の芯を直感で端的に言い表したもの。
完成された結論ではなく、これから制作へ向かう種としての言葉。

とりね洞では、過去のとりねが空間的に漂い、
ふいに「残り香」として強く立ち上がる瞬間がある。

整理して見せる場所ではなく、ふと出会う場所。

---

## 時代の中での位置づけ

体験は流れていく。
鑑賞の直後にあった「何か」も、書き留めなければ消えるし、書き留めても整理されすぎれば芯が抜ける。

あいろは、鑑賞のあとに残った芯を、形になる手前のまま掬い、
それを制作へつなぐための場所。

外で起きたことを、自分の制作の血肉に変えていく経路。

## 技術構成

- フレームワーク不使用（生のHTML/CSS/JS）
- データ保存：localStorage（`airoLogs` / `airoWorks`）
- フォント：Zen Maru Gothic
- LLM（生成AI）未使用

### ファイル構成

```
airo/
├── index.html          あいろ（入力）
├── logs.html           ログ一覧
├── insight.html        いんさいと
├── torine.html         とりね洞
├── works.html          制作
├── works-log.html      制作ログ
├── about.html          あいろの説明
├── manifest.json       PWA設定
├── README.md           この文書
├── CONCEPT.md          コンセプトドキュメント
├── LICENSE.md          ライセンス
└── bg.png              背景画像
```

### ローカルで動かす

簡易サーバーで起動する。

```bash
# Python 3
python3 -m http.server 8000

# Node.js
npx serve
```

ブラウザで `http://localhost:8000` を開く。

### GitHub Pagesで公開

すでに `https://oga-lab.github.io/airo/` で公開中。
変更を `main` ブランチにpushすれば自動でデプロイされる。

### スマホのホーム画面に追加

公開URLをスマホで開く：

**iPhone (Safari)**
1. URL を Safari で開く
2. 共有ボタン → **ホーム画面に追加**

**Android (Chrome)**
1. URL を Chrome で開く
2. メニュー → **ホーム画面に追加**

### データの保存場所

すべてのデータはブラウザの **localStorage** に保存される。
端末の中だけにあり、外部サーバーには一切送信されない。

ブラウザのデータを消去するとデータも消えるので、
バックアップ機能（JSONエクスポート）で書き出しておける。
